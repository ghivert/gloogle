# Vite tooling

Vite is an awesome software widely used in frontend development. Made for
JavaScript, it's also possible to use it with Gleam (thanks to `vite_gleam`),
but need some additional interfaces to leverage it completely. Vitools provides
a consistent suite of tooling to work with Vite, while making sure no bug will
be issued on another platform: you can freely embed `vitools` in any environment
(Vite of course, but why not Lustre Dev Tools?), and `vitools` will not crash
your application.

## Installation

```
gleam add vitools
```
